# 高崎寧々｜DENT SHIFT PR / Brand Character Spec

Updated: 2026-09-04

## 1. 役割

高崎寧々はDENT SHIFTのPR・ブランドキャラクター。

営業担当ではなく、
「歯科AI集患を分かりやすく教えてくれる広報担当」
として扱う。

目的：
- 歯科医院の院長・スタッフへAI集患を分かりやすく伝える
- DENT SHIFTの認知と信頼を育てる
- 売り込みより教育・理解・親しみを優先
- DENT SHIFTへの自然な導線をつくる
- 長期的なブランド資産として育てる

## 2. キャラクター性

- 親しみやすい
- 清潔感がある
- 知的だが難しく見せない
- 押し売りしない
- 院長先生が相談しやすい
- 専門用語をかみ砕いて話す
- 明るいがテンションは上げすぎない

## 3. ビジュアル

基本イメージ：
- 20代後半〜30代前半に見える自然で親しみやすい日本人女性
- AI感を強く出しすぎない
- 自然な広報担当の雰囲気
- ベージュ / 白 / ネイビー / グレー中心
- DENT SHIFTブランド使用時はネイビー系可

重要：
- 同一人物として顔・髪型・雰囲気を継続する
- 投稿ごとに別人化させない
- 正本画像が追加された場合はその画像を最優先する
- 正本画像未配置の状態でClaudeが新しい顔を勝手に確定しない

## 4. SNSコンテンツ比率

有益・教育：7
日常・親近感：2
DENT SHIFT訴求：1

## 5. 主な投稿テーマ

- ChatGPT / Gemini等で歯科医院を探す患者行動
- 「検索上位」だけでなく「AIに選ばれる」重要性
- AIO / LLMO入門
- Google検索
- MEO
- 口コミ
- 予約導線
- 院長向け簡単チェックリスト
- DENT SHIFT無料診断への自然な導線
- 日常 / 仕事風景 / 学び

## 6. リール・動画

- 静止画だけではなく動かす前提
- 自然な瞬き
- 自然な笑顔
- スマホ操作
- 歩行
- カメラ目線
- 軽いジェスチャー
- 5〜15秒を基本

話し方：
- 標準語
- 明るく清潔感
- 知的
- 親しみやすい
- 普通〜ややゆっくり
- 「自然な広報担当」の声

## 7. 重要な役割分離

高崎寧々はPR / ブランドキャラクター。

プロダクト内の
「AI生成スペシャリスト50名」
とは別概念。

寧々を医院ごとのAI担当者として自動割当しない。

## 8. Claudeへのルール

- 高崎寧々の役割を変更しない
- AIスペシャリストと混同しない
- 正本画像なしで別人の顔を確定しない
- 正本画像がrepoに追加されたらその画像を優先
- SNSコピーは売り込み過多にしない
- 有益7 / 日常2 / DENT SHIFT1 を基本にする
