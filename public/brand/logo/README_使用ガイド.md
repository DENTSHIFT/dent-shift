# DENT SHIFT ロゴ納品データ

## フォルダ構成
- 01_master: 高解像度・背景透過のマスターPNG
- 02_png_web: Web・SNS・各種アイコン向けサイズ別PNG
- 03_jpeg: 白背景のJPEG（名刺案・Office資料向け）
- 04_svg: Web・拡大表示向けSVG
- 05_print_pdf: 印刷会社・名刺制作向けPDF
- 06_favicon: Webサイト用favicon一式

## 正式カラー
- NAVY: #0F1B2D / RGB 15, 27, 45
- BLUE: #2563EB / RGB 37, 99, 235

## 推奨用途
- Webヘッダー: 02_png_web/DENT_SHIFT_horizontal_800px.png または 04_svg/DENT_SHIFT_horizontal.svg
- SNS・アプリアイコン: 02_png_web/DENT_SHIFT_symbol_512px.png
- favicon: 06_favicon/favicon.ico
- 名刺・印刷: 05_print_pdf/DENT_SHIFT_print_logo.pdf
- PowerPoint・Word: 03_jpeg/DENT_SHIFT_horizontal_white.jpg

## 使用上の注意
- ロゴの縦横比を変更しない
- 色を任意に変更しない
- 影・縁取り・回転を加えない
- 背景が濃色の場合は視認性を必ず確認する
- JPEGは透過非対応。透明背景が必要な場合はPNGまたはSVGを使用する
