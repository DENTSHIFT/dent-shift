# DENT SHIFT — Product Spec (P0)

出典: 「DENT SHIFT → Claude Code 完全引き継ぎマスター Ver.2」(2026-09-03)。矛盾が生じた場合は `DENT_SHIFT_CLAUDE_HANDOFF.md` およびユーザー本人の確認を優先する。

## 1. プロダクト定義

DENT SHIFTは「歯科医院専用AI集患OS」。単なるSEO/AIO・LLMO分析ツールや広告運用ツールではない。

入口は医院名または公式サイトURL。AI検索・SEO・MEO・口コミ・Web予約導線・広告等を横断し、以下を一気通貫で可視化・改善する。

- AIに医院情報が正しく認識されているか
- 患者が使う質問で競合医院に勝っているか
- なぜ負けているのか
- 次に何を改善すべきか
- 改善後にAI露出・流入・予約・新患がどう変化したか

タグライン: 「歯科集患を、AIでシフトする。」

事業モデルの思想: 歯科医院専用 / 営業電話なし / 商談必須にしない / オンライン完結 / AIが分析し必要なときだけ人が支える / レポートで終わらず予約・新患成果までつなげる。

## 2. 絶対に変えない事業ルール(要約)

1. 主単位は「人」ではなく歯科医院。`clinic_id` を軸に診断・契約・改善・相談・連携・決済を一元化。
2. 無料診断〜契約まで原則電話番号不要。営業電話・商談必須を前提にしない。
3. 患者個人情報(氏名・電話・メール・病歴・診療記録・相談本文・予約フォーム本文)は原則保存しない。
4. 外部公開・広告変更・GBP変更・医院サイト変更・口コミ返信・医療情報公開は、人の明示承認なしに自動実行しない。
5. APIエラー・取得不能値を0として扱わない。推定値は「推定」、サンプルは「サンプル」と明示する。
6. 因果を証明できない結果を断定表現で語らない。
7. 料金・プラン・AI provider/API仕様はハードコードせず設定化する。
8. AI生成人物(担当者)は実在社員と誤認させない。必ず「AI生成モデル」と表示する。
9. 広告代理店化しない。自然AI推薦とAI広告を混同しない。歯科特化を外して汎用SaaS化しない。
10. CRMはSalesforce/HubSpot等の外部SaaSに依存せず自社開発する。

## 4. P0(MVP)スコープ

リリース目標: **2026-10-01**。「無料診断 → 結果 → 契約 → 初期利用」のコア体験を成立させることに集中し、P1/P2機能をP0に混ぜない。

### 無料診断入力
医院名 / 公式サイトURL / メールアドレス(電話番号は取得しない)

### 契約後・任意入力
GBP / 予約URL / 診療科目 / 強化したい自費診療 / 商圏 / 最寄駅 / 診療時間 / 院長名 / 比較競合 / 目標予約・新患数

### 診断結果(6領域100点)
AIO 30 / MEO 20 / SEO 15 / LLMO 15 / Web・予約導線 10 / 口コミ・信頼性 10

加えて: ChatGPT/Gemini主要計測、AI推薦シェア(Share of Voice)、患者質問別競合勝敗、競合3院比較、敗因、改善TOP3、医療広告リスク、測定条件・取得日時。

詳細な受入基準は `P0_ACCEPTANCE.md` を参照。

## 6. プロダクト判断基準

新機能追加時に以下を自問し、3つ以上「No」ならMVPでは後回し。

1. 院長の意思決定が早くなるか
2. 予約・新患につながるか
3. 競合との差が分かるか
4. 次の行動が具体的になるか
5. 歯科医院専用の意味が強くなるか
6. 営業マンなしで利用開始しやすいか
7. P0に本当に必要か
