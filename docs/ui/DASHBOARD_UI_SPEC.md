## スペシャリスト相談CTA(配置方針、2026-09-06のユーザー指示)

本契約後の正式ダッシュボードにも、無料診断結果画面(src/app/diagnosis/result/[id]/page.tsx
のConsultationCta)と同じ設計思想の「専門スタッフに相談する」CTAを常設する前提とする。
相談枠の見出しは「スペシャリストに相談する」に統一し、所要時間の45分はバッジ等で別表示する。
ただし現時点(このドキュメント更新時点)は本契約後ダッシュボードの実装フェーズではないため、
コード実装はまだ行わない。このセクションは実装時に迷わないための構造メモ。

配置候補(実装時にレイアウトへ合わせて選択・併用してよい):
- ダッシュボード上部(「TOPダッシュボード」上段のスペシャリスト相談CTA)
- 改善TOP3付近(院長が「次に何をすべきか」を見た直後に相談導線を提示する)
- 必要に応じて右サイド(サイドナビ「スペシャリスト相談」と重複しても構わない。
  ページ内の目立つ位置に常設CTAを置く狙いのため)

必須ルール(無料診断結果画面のConsultationCtaと同一の方針を維持する):
- 相談は任意。診断結果の閲覧・ご契約・ダッシュボードの利用条件にはしない
  (「相談しないと使えない」ように見せない)。
- 予約先URLはコードへ直書きせず、環境変数(NEXT_PUBLIC_SPECIALIST_BOOKING_URL)、
  またはTimeRex契約後に確定する正式な予約設定から読み込む。
- 未設定時は壊れたリンクや空枠を表示せず、CTA自体を描画しない
  (親レイアウトに余分な余白・空行を残さない実装にする。無料診断結果画面の実装を参照)。
- 実在人物風の見せ方(担当者名・アバター等の断定的表示)はしない。AI生成の人物表示を
  将来追加する場合は「AI生成モデル」の明示を必須にする(HANDOFF.md 25章)。

## メインカード1

AIで選ばれている割合

表示例：
自院
競合A
競合B
その他

切替候補：
- ChatGPT
- Gemini
- Google AI Mode
- 全体

診療テーマ/エリアでフィルタ可能にする。

## メインカード2

患者質問ごとのAI表示状況

状態：
- 表示良好
- 拮抗
- 改善余地あり
- データ不足

質問ごとに競合医院との差を表示。

## メインカード3

改善余地がある理由

例：
- 症例不足
- FAQ不足
- 口コミ数/鮮度
- 院長プロフィール
- 第三者媒体
- 構造化データ
- GBP
- AI誤認
- クロール障害

各項目：
- 根拠
- 影響度
- 確度
- 対象URL

原因を断定しない。

## メインカード4

今月やるべきこと TOP3〜5

各アクション：
- 優先度
- 想定工数
- 担当
- 完了状態
- 再計測日

TOP3を最優先表示。

## メインカード5

AIから予約まで

AI推薦
→ AI経由サイト流入
→ 診療ページ閲覧
→ 予約CTA
→ フォーム開始
→ 予約完了
→ 新患

不足データを推測補完しない。

## 状態表示

必ず区別する：
- loading
- success
- empty
- not_configured
- needs_reauth
- temporarily_unavailable
- insufficient_data
- error

「0」と「データなし」を同じ表示にしない。
