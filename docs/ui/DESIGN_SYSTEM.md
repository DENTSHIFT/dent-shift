# DENT SHIFT Design System

## 基本方針

DENT SHIFTは歯科医院向けAI集患SaaS。

デザインのキーワード：
- 清潔感
- 信頼感
- 医療
- SaaS
- AI
- シンプル
- 分かりやすい
- 院長が迷わない

## ブランドカラー

正式な色指定は public/brand/logo 内のブランドガイドを最優先する。

基本トーン：
- White
- Navy
- Blue
- Light Gray

Claudeはブランドガイドを確認せず独自カラーへ変更しない。

## ロゴ

正本：
public/brand/logo/

横長ロゴ、シンボル、faviconを用途に応じて使用する。

禁止：
- ロゴの変形
- 色変更
- 比率変更
- 独自再デザイン
- AIによる作り直し

## UIスタイル

- 白ベース
- ネイビー/ブルーをアクセント
- 角丸カード
- 十分な余白
- SaaSらしい整理された情報設計
- 数字を大きく
- 状態を色だけで判断させない
- モバイル対応
- 専門用語を前面に出さない

## 表示原則

院長向け画面では、
API / MCP / OAuth / JSON等の技術用語を前面に出さない。

優先する表現：
- AIで選ばれている割合
- 競合との差
- 患者質問ごとのAI表示状況
- 改善余地がある理由
- 今月やるべきこと
- AIから予約まで
