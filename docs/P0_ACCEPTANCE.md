# DENT SHIFT — P0 Acceptance Checklist

各項目は「無料診断 → 結果 → 契約 → 初期利用」のコア体験が成立しているかを判定する基準。実装完了の主張には、この一覧に対する自己チェックを添える。

## 診断入口
- [ ] 医院名または公式サイトURLから診断を開始できる
- [ ] 電話番号の入力を要求していない
- [ ] 送信時に医院レコードが作成される
- [ ] 既存医院との重複候補を検出できる(完全一致 or ドメイン一致レベルでよい)

## 診断結果の受け取り
- [ ] メールで結果を受け取れる(電話連絡なし)

## スコアリング
- [ ] 6領域100点で採点される(AIO30 / MEO20 / SEO15 / LLMO15 / Web・予約導線10 / 口コミ・信頼性10)
- [ ] ChatGPT / Gemini を計測対象として扱っている(P0初期はmockでも可、`is_sample` を明示)
- [ ] 医院言及・引用・情報正確性を計測項目に含んでいる
- [ ] 競合3院との比較ができる
- [ ] AI推薦シェア(Share of Voice)を算出している
- [ ] 患者質問別の勝敗を表示できる
- [ ] 敗因(候補)を表示できる
- [ ] 改善TOP3を提示できる
- [ ] 医療広告リスクの簡易チェックを行っている
- [ ] 測定条件・取得日時を結果に明記している

## 契約・決済
- [ ] プラン比較画面がある
- [ ] オンラインで契約が完結する(商談必須にしない)
- [ ] 決済状態(`trial/active/past_due/restricted/suspended/cancel_scheduled/cancelled`)を管理している

## オンボーディング・相談
- [ ] 契約後の初期オンボーディングフローがある
- [ ] スペシャリスト相談は「希望者のみ」の任意導線になっている(必須にしていない)

## アンバサダー
- [ ] 紹介コードを発行できる
- [ ] 「紹介 → 診断 → 契約 → 初回入金」の流れを追跡できる
- [ ] 成果判定は「有料契約 + 初回入金完了」時点であり、クリックのみを成果にしていない

## 権限・監査
- [ ] 医院側/運営側で権限が分離されている
- [ ] 外部書き込みを伴う操作に監査ログが残る

## データ・表現の安全性
- [ ] 患者個人情報(氏名/電話/メール/病歴/診療記録/相談本文/予約フォーム本文)を一切保存していない
- [ ] 取得不能値を0として表示していない
- [ ] サンプル/mockデータを実績として表示していない
- [ ] 推定値には「推定」の明示がある

これらのうち未達成の項目がある状態で「MVP完成」と報告しない。
