# DENT SHIFT — P0 Acceptance Checklist

各項目は「無料診断 → 結果 → 契約 → 初期利用」のコア体験が成立しているかを判定する基準。実装完了の主張には、この一覧に対する自己チェックを添える。

## 診断入口
- [x] 医院名または公式サイトURLから診断を開始できる(実装は両方必須。PRODUCT_SPEC.md 4章の
      入力項目定義に合わせ、当初の「いずれか」から要件が確定したもの)
- [x] 医院の代表電話番号を必須入力とし、患者の電話番号とは分離している
- [x] 送信時に医院レコードが作成される
- [x] 既存医院との重複候補を検出できる(完全一致 or ドメイン一致レベルでよい)

## 診断結果の受け取り
- [x] メールで結果を受け取れ、結果画面でも送信状態を確認できる(電話連絡なし)

## スコアリング
- [x] 6領域100点で採点される(AIO30 / MEO20 / SEO15 / LLMO15 / Web・予約導線10 / 口コミ・信頼性10)
- [x] ChatGPT / Gemini を計測対象として扱っている(P0初期はmockでも可、`is_sample` を明示)
- [x] 医院言及・引用・情報正確性を計測項目に含んでいる
- [x] 競合3院との比較ができる(`competitorProvider.findNearbyCompetitors`、結果画面の競合カード表示)
- [x] AI推薦シェア(Share of Voice)を算出している(`domain/competitor/shareOfVoice.ts`。
      患者質問のうちstatus==="win"の割合。測定対象0件時は0%ではなく「算出できませんでした」と
      表示し、取得不能値を0として扱わない方針を維持。結果画面の総合スコアカードに表示)
- [x] 患者質問別のAI表示状況を中立的な表現で表示できる
- [x] 改善余地がある理由(候補)を表示できる
- [x] 改善TOP3を提示できる
- [x] 医療広告リスクの簡易チェックを行っている
- [x] 測定条件・取得日時を結果に明記している(日本時間)

## 契約・決済
- [x] プラン比較画面がある(料金未確定時は決済を開始しない)
- [x] オンラインで契約が完結する(商談必須にしない。Stripeサンドボックスで決済完了まで確認済み)
- [x] 決済状態(`trial/active/past_due/restricted/suspended/cancel_scheduled/cancelled`)を管理している(署名検証付きWebhook接続・初回入金反映まで確認済み)

## オンボーディング・相談
- [x] 契約後の初期オンボーディングフローがある
- [x] スペシャリスト相談は「希望者のみ」の任意導線になっている(必須にしていない)

## アンバサダー
- [x] 紹介コードを発行できる(最小仕様。報酬率・発行フローの運用UIは未整備、`Ambassador`モデル参照)
- [x] 「紹介 → 診断 → 契約 → 初回入金」の流れを追跡できる(`Attribution`テーブル、signup時pending記録)
- [x] 成果判定は「有料契約 + 初回入金完了」時点であり、クリックのみを成果にしていない
      (`confirmAttributionForClinic`はStripe `invoice.paid`到達時のみconfirmedへ遷移)

## 権限・監査
- [x] 医院側/運営側で権限が分離されている(`Operator`モデル+`/ops/login`+`ds_ops_session`
      Cookieで医院側`Contact`/`ds_session`とは完全に別の認証ドメイン。SECURITY.md準拠。
      Operatorの自己サインアップは提供せず`scripts/create-operator.ts`で個別発行する)
- [x] 外部書き込みを伴う操作に監査ログが残る(`AuditLog`モデル、`recordAuditLog()`。現状は
      opsログインとクロステナント医院一覧参照を記録。実際の外部書き込み機能(GBP変更等)は
      まだ存在しないため、それらを実装するタイミングで同じ`recordAuditLog()`を呼び出す)

## データ・表現の安全性
- [x] 患者個人情報(氏名/電話/メール/病歴/診療記録/相談本文/予約フォーム本文)を一切保存していない
- [x] 取得不能値を0として表示していない
- [x] サンプル/mockデータを実績として表示していない
- [x] 推定値には「推定」の明示がある

これらのうち未達成の項目がある状態で「MVP完成」と報告しない。
