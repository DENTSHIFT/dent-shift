# TimeRex 埋め込みウィジェット url_params(ds_ref)欠落調査 — 2026-10-03

スコープ: `dent-shift-test`(test.dentshift.jp)、TimeRex「DENT SHIFT検証専用チーム」のみ。本番(dentshift.jp)・本番Salesforceへの影響はない。本番移行は未承認・保留。

## 背景

`/consult`・ダッシュボード・診断結果ページの「無料相談」導線を、TimeRex埋め込みウィジェット(`window.TimerexCalendar({url_params:{...}})`)経由に統一し、医院紐付け用の署名付き参照`ds_ref`をurl_params経由でWebhookまで届ける修正(commit `583316c`)を`dent-shift-test`のProduction環境へデプロイ済み。

## 事象

承認済みテスト医院の担当者(木村氏)が、`/consult`の埋め込みウィジェット上の時間枠を実際にクリックして日程調整を完了したにもかかわらず、受信したWebhook(`event_confirmed`)の`event.url_params`に`ds_ref`が含まれていなかった。

- TimeRex event id: `dfef9bfc3b3e70d79f94`
- team_url_path: `dentshift-verify-20261003`(DENT SHIFT検証専用チーム)
- calendar_url_path: `af98dc08`、calendar_id: `f2f92627306d680ace3b`(検証用予約カレンダー)
- 予約日時: 2026-10-05 08:00-09:00 Asia/Tokyo(UTC: 2026-10-04T23:00:00Z - 2026-10-05T00:00:00Z)
- TimeRex側作成日時: 2026-10-03T02:35:06+00:00
- Webhook受信(event_confirmed): 2026-10-03T02:35:09+00:00(JST 11:35:09)、HTTPステータス200、レスポンスボディ `{"status":"recorded","matched":false}`
- `event.url_params`: 存在せず(欠落)
- DB: `ConsultationBooking.id = cmurs4ksx0001vqv07stu304o`
  - 取消前: `status = confirmed`、`matchMethod = unmatched`、`clinicId` 空欄

事前条件(チーム・カレンダー・Webhook送信先)はいずれも想定通り(検証専用チーム/検証専用カレンダー/test.dentshift.jp宛て)であることをWebhookペイロードから確認済み。チーム・カレンダーが正しいこと自体は医院紐付け成功の証拠にはならない。

## 再現テストで確認できたこと(予約完了後の別セッションでの観測)

- `/consult`を新規読み込みした際、埋め込みiframeの初回ドキュメントリクエスト(1件のみ)のURLに`ds_ref`がクエリとして付与されていることをブラウザの開発者ツールで確認(キー名のみ確認、値は記録せず)。
- `window.TimerexCalendar`は1回呼び出され(ネットワークリクエストが1件のみであることから推認)、コンソールエラーなし、iframe/子要素の重複なし(二重初期化の形跡なし)。
- デプロイ(`583316c`、2026-10-03 01:58 UTC頃完了)は、問題の予約のWebhook受信(02:35 UTC)より前であり、タイミング上は古いバンドルが配信された形跡はない(ただしブラウザ側キャッシュの可能性までは排除できていない)。
- 上記はいずれも**予約完了後の再読み込み時の観測であり、問題が起きた予約そのものの際の通信記録ではない**。
- 自動操作(ブラウザ拡張によるクリック)ではこのクロスオリジンiframe内の時間枠クリックを再現できず、日程選択ステップより先へ進めることができなかった。これは「ツール側の制約」と断定できる段階にはなく、原因未特定。木村氏本人の実際のクリックでは予約が成立しているため、人の操作では少なくとも日程選択自体は可能。

## 現状の結論

クライアント側(dent-shift側のウィジェット初期化コード)の再現テストでは不具合を発見できなかった。実際の予約でなぜ`url_params`が欠落したかは、TimeRex埋め込みウィジェット内部(日程選択→情報入力→確定)の処理過程にある可能性が高いと考えられるが、クロスオリジンのため内部状態を直接観測できず、特定には至っていない。「直接リンク非対応」「ツール制約」等の断定はしていない。
